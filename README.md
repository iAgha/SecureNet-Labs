# SecureNet-Labs  
  
A structured hands-on Cisco networking portfolio built using Packet Tracer, progressing from foundational labs to enterprise-scale simulations — all designed with integrated security thinking and SOC-focused scenarios.  
  
---  
  
## 📂 Repository Structure  
  
### 🔹 Level 1 – Foundations  
Core networking labs covering:  
  
- LAN Switching & Port Security  
- Subnetting & IP Planning (VLSM)  
- VLAN & Inter-VLAN Routing  
- DHCP & DNS Services  
- ACL Implementation (Standard & Extended)  
- NAT & PAT  
- OSPF (Single Area)  
- STP Fundamentals  
- Basic Site-to-Site VPN Concepts  
  
Each lab includes:  
- Network Objective  
- Security Enhancement  
- SOC Scenario Simulation  
- Investigation Insight  
  
---  
  
### 🔹 Level 2 – Integrated Network Design  
  
Multi-layer network implementations:  
  
- Small Company Secure Network  
- Secure Office Architecture  
- DMZ Deployment  
- Redundant Network Design  
  
Focus:  
- Segmentation Strategy  
- Least Privilege Access  
- Traffic Control Policies  
- Internal Threat Awareness  
  
---  
  
### 🔹 Level 3 – Enterprise Simulation  
  
Enterprise-grade network architecture:  
  
- Medium Enterprise  
- Multi-Branch Company  
- Bank Network Simulation  
  
Focus:  
- Secure Architecture Design  
- High Availability  
- Lateral Movement Prevention  
- Incident-Oriented Thinking  
  
---  
  
### 🔹 AI Assistance  
  
This repository leveraged AI-assisted tools to:  
  
- Generate project documentation and README templates  
- Structure lab progression and repository organization  
- Provide suggestions for SOC-focused scenarios  
  
AI was used as a **supporting tool**; all network designs, configurations, and project implementations were personally executed.

To build deep practical networking expertise while applying real-world security concepts and SOC-level investigation thinking to each lab.
